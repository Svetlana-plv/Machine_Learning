# Лабораторные работы: Машинное обучение и анализ данных

Данный репозиторий содержит выполненные лабораторные работы по курсу «Машинное обучение и анализ данных». 
В качестве основного источника данных используется синтетический датасет дорожного трафика, на котором решаются задачи анализа данных и бинарной классификации.

| :--- | :--- |

## Данные (Датасет)

**Дедлайн:** 02.10.2026

**Файл:** [`synthetic_traffic_benchmark_200k.csv`](./synthetic_traffic_benchmark_200k.csv)  

Синтетический бенчмарк дорожного трафика, содержащий ~200 000 записей о дорожных событиях. Включает информацию о времени, типе дороги, погодных условиях, видимости, характеристиках водителя и транспортного средства, а также сведения о произошедших ДТП.

## Задание №3: Задача классификации

**Дедлайн:** 23.10.2026

**Файл:** [`lab-3-traffic-accident-classification.ipynb`](./lab-3-traffic-accident-classification.ipynb)   

**Постановка задачи:** 
Построение и сравнение моделей машинного обучения для решения задачи **бинарной классификации** — предсказания факта ДТП (`Accident_Occurred`) на основе контекстных условий, характеристик дороги, погоды и параметров водителя.
